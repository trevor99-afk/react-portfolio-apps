# React Portfolio Apps

Ten independent, interactive React + TypeScript + Vite apps in one npm-workspaces repo. Each app uses local demo data and works without API keys or a backend.

**Live demos:** https://trevor99-afk.github.io/react-portfolio-apps/

## Get started

1. Install Node.js 18 or newer.
2. Run `npm install` from this folder.
3. Start an app with `npm run dev:finance` (replace `finance` with an app below).
4. Run `npm run build` to build every app, or `npm run typecheck` to type-check the source.
